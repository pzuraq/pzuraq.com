# pzuraq.com

A personal blog built with [React Router](https://reactrouter.com/) (framework mode),
[Signalium](https://signalium.dev/) for reactivity, [MDX](https://mdxjs.com/) for content, and
[Tailwind CSS](https://tailwindcss.com/).

The entire site is prerendered at build time (`ssr: false` + `prerender` in
`react-router.config.ts`) and deployed as
[Cloudflare Workers static assets](https://developers.cloudflare.com/workers/static-assets/) —
there is no server code and no Worker cold starts. Redirects and custom headers are handled by
the `_redirects` (generated by `scripts/postbuild.mjs`) and `public/_headers` metafiles, and the
404 page is a prerendered `404.html`.

## Developing

```bash
npm install
npm run dev
```

## Blog posts

Posts live in `app/posts/` as `YYYY-MM-DD-slug.mdx` files. The publish date and URL slug are
derived from the filename, and each post has `title` and `tagline` frontmatter (plus an optional
`hide` flag to exclude it from the index). Post metadata is extracted at build time by the Vite
plugin in `lib/post-meta.ts`, which also feeds the RSS feed and sitemap.

## Building and deploying

```bash
npm run build    # production build (prerenders all routes + postbuild step)
npm run preview  # build and serve the static output with wrangler dev
npm run deploy   # build and deploy to Cloudflare Workers
```

## Checks

```bash
npm run check    # typecheck (react-router typegen + tsc)
npm run lint     # prettier + eslint
npm run format   # prettier --write
```
